# FedotovskiiLev — personal site

A deliberately minimal personal landing page with an animated ASCII accretion disk.

## Current projects

1. **MIPT Interactive Materials** — independent interactive university materials for mathematics, physics, lab work, data analysis and a study library.
2. **Setka / Сетка** — university planner.
3. **FAILED Calculator** — mathematical experiment with degrading memory.
4. **Zeitgeist** — codename for a simulation-sandbox project currently in development.
